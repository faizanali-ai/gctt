{% if "agile" in programme.slug or "scrum" in programme.slug %}
01

Agile Foundations & Scrum Theory

Deep dive into Agile values, principles, and the Scrum 3-5-3 architecture (3 Roles, 3 Artifacts, 5 Events). Transitioning mindset from command-and-control to servant leadership.

02

Sprint Ceremonies & Facilitation Mastery

Mastering the mechanics and practical facilitation of Sprint Planning, Daily Scrums, Sprint Reviews, and high-impact Retrospectives with continuous improvement action items.

03

Backlog Grooming, User Stories & Estimation

Writing robust user stories using INVEST criteria, defining precise Acceptance Criteria, story point sizing (Fibonacci / Planning Poker), and managing backlog health.

04

Jira Software Administration & Agile Telemetry

Hands-on configuration of Scrum boards, sprint workflows, release versioning, burndown/burnup velocity tracking, cumulative flow diagrams, and stakeholder reporting.

05

Impediment Resolution & Scaled Agile (SAFe)

Shielding delivery squads, removing cross-team blockers, resolving conflicts, and navigating enterprise scaled agile environments (PI Planning, dependencies, and release trains).

06

Capstone Simulation, Certification & Career Coaching

Live sprint simulation with real-world enterprise delivery scenarios, rigorous certification exam preparation, 1-on-1 interview rehearsal, and public certificate issuance.

{% elif "business-analyst" in programme.slug %}
01

Enterprise BA Fundamentals & Scope Management

The core role of the modern Business Analyst, SDLC models, business case formulation, stakeholder matrix mapping, and defining project scope boundaries.

02

Requirements Elicitation Techniques

Conducting stakeholder interviews, Joint Application Development (JAD) workshops, document analysis, prototyping, and translating ambiguities into clear technical requirements.

03

BRD, FRD & Specification Authoring

Writing enterprise Business Requirements Documents (BRD), Functional Requirement Documents (FRD), System Requirement Specifications (SRS), and Requirements Traceability Matrices (RTM).

04

Process Modeling (BPMN 2.0) & Gap Analysis

Hands-on visual workflow modeling using BPMN 2.0 in Lucidchart/Visio: As-Is vs To-Be process architecture, swimlane diagrams, data flow diagrams, and gap identification.

05

Agile Story Mapping, Jira Backlog & UAT

Transforming functional specifications into Jira epics and user stories with Gherkin acceptance criteria. Designing User Acceptance Testing (UAT) test cases and signing off releases.

06

End-to-End Enterprise Project & Verifiable Credential

Capstone project simulating an enterprise platform upgrade, executive stakeholder presentation review, mock technical interview calibration, and credential issuance.

{% elif "devops" in programme.slug %}
01

Linux Systems Administration & Shell Automation

Enterprise Linux fundamentals, user permissions, networking (DNS, SSH, firewalling), process monitoring, and writing Bash automation scripts.

02

Version Control & Distributed Git Workflows

Git architecture, trunk-based vs GitFlow branching, merge conflict resolution, pull request code review gates, and security hooks.

03

Docker Containerization & Image Optimization

Building containerized application environments, writing multi-stage Dockerfiles, managing container networks/volumes, and Docker Compose orchestration.

04

CI/CD Pipeline Automation (Jenkins & GitHub Actions)

Designing automated build, test, and deployment pipelines. Declarative Jenkinsfiles, GitHub Actions workflows, secret management, and artifact publishing.

05

Cloud Infrastructure (AWS) & Terraform (IaC)

Core AWS services (EC2, VPC, S3, IAM, RDS), Infrastructure as Code with Terraform, state management, and immutable infrastructure patterns.

06

Kubernetes Orchestration & Production Monitoring

Deploying and managing Kubernetes clusters (Pods, Services, Ingress, Deployments), monitoring with Prometheus/Grafana, and verifiable certification issuance.

{% elif "ba-sm" in programme.slug %}
01

Hybrid Delivery Model Foundations

The dual-discipline advantage: uniting Business Analysis (what to build) with Scrum Master facilitation (how to deliver with speed and quality).

02

Requirements Decomposition into Agile Backlogs

Eliciting high-level enterprise business requirements and decomposing them directly into actionable Jira epics, user stories, and acceptance test cases.

03

Sprint Planning & Story Sizing Dynamics

Leading cross-functional estimation sessions, balancing technical debt with functional features, and aligning developer capacity with product roadmaps.

04

Ceremony Leadership & Conflict De-escalation

Facilitating daily standups, backlog refinement, sprint demos, and retrospectives. Removing delivery bottlenecks and managing business expectations.

05

Delivery Telemetry & Executive Reporting

Tracking squad velocity, cycle time, burndown charts, and presenting sprint deliverables clearly to senior engineering and enterprise business directors.

06

Dual-Role Capstone & Verifiable Credential

End-to-end product delivery simulation acting as both BA and Scrum Master, career positioning coaching, and Texas E-Verify credential issuance.
